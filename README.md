# Prompt with Weight Generator

GUIベースのプロンプト生成アプリケーションです。タグを管理し、重み付きでプロンプトを生成できます。

**Mac用デスクトップアプリケーションとして実行可能です。**

## 機能

### 主要機能
- **プロンプト生成**: タグを選択して重み付きプロンプトを生成
- **タグ管理**: タグの登録・削除が可能
- **カテゴリ別ソート**: プロンプトはカテゴリごとにソートして生成
- **重み付け**: 0.0〜2.0の範囲でタグに重みを設定可能
- **クリップボードコピー**: ワンクリックでプロンプトをコピー
- **データ永続化**: タグはローカルストレージに自動保存

### UI構成

#### 画面上部: プロンプトエリア
- 生成されたプロンプトを表示するテキストエリア
- クリップボードにコピーできるコピーボタン

#### 画面下部: タグセクション
- **タグ登録フォーム**
  - タグ名入力フィールド
  - カテゴリ入力フィールド
  - 登録ボタン
- **タグ一覧**
  - 登録済みタグがボタンで表示
  - 各タグボタンにはカテゴリラベルと削除ボタンが付属

#### フロートウィンドウ（モーダル）
- タグボタンクリックで表示
- 重み入力フォーム（0.0〜2.0、小数点第一位）
- 挿入ボタンとキャンセルボタン

## セットアップ

### 依存関係のインストール

```bash
npm install
```

## 使い方

### 1. アプリケーションの起動

#### 推奨: Electronアプリとして起動（Mac/Windows/Linux）
```bash
npm start
```

#### 方法2: ビルド済みアプリケーションを使用（Mac）
```bash
# Mac用のアプリケーションをビルド
npm run build

# ビルドされたアプリは dist/ ディレクトリに生成されます
# dist/mac/Prompt Generator.app をダブルクリックして起動
```

#### 方法3: 直接HTMLファイルを開く（開発用）
```bash
# ブラウザでindex.htmlを直接開く
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows
```

### 2. タグの登録

1. 「タグ名」フィールドにタグを入力（例: `beautiful scenery`）
2. 「カテゴリ」フィールドにカテゴリを入力（例: `subject`）
3. 「タグを登録」ボタンをクリック

### 3. プロンプトの生成

1. 登録済みタグ一覧からタグボタンをクリック
2. フロートウィンドウが表示される
3. 重みを入力（オプション）
   - 空欄の場合: タグのみ挿入（例: `beautiful scenery`）
   - 入力した場合: 重み付きで挿入（例: `(beautiful scenery:1.5)`）
4. 「挿入」ボタンをクリック

### 4. プロンプトのコピー

- プロンプトエリア右上の「📋 コピー」ボタンをクリック
- クリップボードにプロンプトがコピーされます

### 5. タグの削除

- タグボタン内の「×」マークをクリック
- 確認ダイアログで「OK」を選択

## プロンプト生成の仕様

### カンマ区切り
- 複数のタグはカンマ（`, `）で区切られます

### カテゴリ別ソート
- プロンプトはカテゴリごとにブロック化されます
- カテゴリ名でアルファベット順にソートされます

### 例

登録タグ:
- `beautiful scenery` (category: `subject`)
- `sunset` (category: `subject`)
- `photorealistic` (category: `style`)
- `4k` (category: `quality`)

挿入順序:
1. `photorealistic` (重み: 1.5)
2. `4k` (重みなし)
3. `beautiful scenery` (重み: 1.2)
4. `sunset` (重みなし)

生成されるプロンプト:
```
4k, (photorealistic:1.5), (beautiful scenery:1.2), sunset
```

カテゴリ順: `quality` → `style` → `subject`

## データの永続化

- タグデータはローカルストレージに自動保存されます
- アプリケーションを閉じても、データは保持されます
- Electronアプリの場合、データはアプリケーション固有のストレージに保存されます
- データをクリアする場合は、開発者ツール（メニュー > ヘルプ > 開発者ツール）から LocalStorage を削除してください
